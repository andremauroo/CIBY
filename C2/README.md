# C2 — Raffinamento e focus

Materiali del progetto CIBY per la consegna del 26 ottobre 2026. Il focus è la **gestione flessibile dei pasti**: partire dagli alimenti disponibili, scegliere una preparazione praticabile e riorganizzare ingredienti e acquisti quando cambiano i programmi.

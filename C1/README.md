## Prima di intervistare

Minimo 3 interviste: almeno un utente target e un utente esperto; con soli 3 intervistati, 2 devono essere target. Durata 30–60 minuti; 2 membri del gruppo presenti, massimo 3. Di persona nel contesto, con call ammessa in caso di difficoltà. Consenso ufficiale firmato su carta prima della raccolta.

Per il target attuale, maggiorenne, usare il modulo ufficiale per adulti già disponibile tra le fonti del progetto. Distinguere le scelte espresse per adesione, diffusione delle interviste e immagini.

## Materiali riservati e materiali da condividere

Conservare separatamente dal repository pubblico contatti, moduli firmati e registrazioni originali. Le risposte condivise devono essere coerenti con le autorizzazioni e con le modalità descritte nei moduli ufficiali. Usare codici partecipante nei report e verificare che anche citazioni, foto e artefatti non introducano identificativi non previsti.

La directory facoltativa `riservato/` è esclusa da Git per ridurre il rischio di aggiunte accidentali; questo non sostituisce il controllo dei file da pubblicare.

## File finale

Salvare il PDF pronto per la consegna in `C1/CIBY-C1.pdf`. È una convenzione proposta dal gruppo: il compito non prescrive un nome di file né un numero di slide.

Le tabelle vuote e le ipotesi iniziali non sono risultati. Non compilare report o bisogni con dati simulati.
